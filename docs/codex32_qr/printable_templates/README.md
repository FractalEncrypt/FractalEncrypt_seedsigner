# Printable codex32 practice cards

[Download the current three-page PDF](Seedsigner_Codex32_Printable_SeedCards.pdf).
Page 1 is a large share card; page 2 is a landscape pair of a share card and QR
worksheet; page 3 has four smaller cards. Print at actual size. Older PNG cards
and the previous PDF have been replaced.

For Alpha 0.1, write PUBLIC TEST ONLY on your practice cards and use the
[NAME A or cash A transcription groups](../Codex32_Experimental_Test_Guide.md#public-bip93-recovery-vectors-text-and-qr).
The blank QR grid is for manual transcription; it is not a pre-filled test QR.
